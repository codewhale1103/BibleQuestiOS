# Story library cover artwork

All ten covers were generated with the built-in `image_gen` tool. David uses `BibleQuest/Assets.xcassets/davidFullBody.imageset/davidFullBody.png` as the identity reference. Covers contain no embedded text; titles and references are native accessible SwiftUI text. Each final PNG is bundled in the asset catalog.
